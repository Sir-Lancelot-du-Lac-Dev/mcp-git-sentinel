## Reporting a Vulnerability

As an MCP server engineered for context protection and secret leak interception, we take security reports seriously.

If you discover a security vulnerability (such as a command injection risk in the Git execution layer, path traversal, or an entropy bypass technique):

1. **Do not create a public issue.**
2. Send an advisory report directly via [GitHub Private Vulnerability Reporting](https://github.com/Sir-Lancelot-du-Lac-Dev/mcp-git-sentinel/security/advisories) or contact the primary maintainer via `346207872+Sir-Lancelot-du-Lac-Dev@users.noreply.github.com`.
3. Include detailed reproduction steps, example diff payloads, and environment details.

We commit to acknowledging reports within **24 hours** and releasing patches within **72 hours** for high-severity findings.
